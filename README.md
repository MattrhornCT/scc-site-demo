# scc-site-demo

Shelby's Cookie Co. website demo (Vite + React, Airtable-backed, order form via `functions/order.js`).

## Live site

- **URL:** https://scc-site-demo.wilderistdemo.workers.dev/
- **Hosting:** Cloudflare, under the **thewilderistmusic@gmail.com** login (not the GitHub-login account). The workers.dev subdomain is `wilderistdemo`; it is separate from the login and can be changed in Workers & Pages.
- **Deploys:** automatic on every push to `main` (Cloudflare Workers Builds).
- **Dashboard:** https://dash.cloudflare.com/98265f51b73317dc96c535f9c1b154cb/workers/services/view/scc-site-demo/production
- **Older copy (July, pre-Cloudflare):** https://mattrhornct.github.io/scc-site-demo/
