# Archive

Drop photos in here to pull them off the live Gallery page without deleting them.
This folder is intentionally excluded from the gallery's image scan (see the
`!../gallery-images/archive/**` exclusion in `src/gallery/loadGallery.js`), so
anything placed directly in `archive/` (or in subfolders under it) never shows up
on the site.

To bring a photo back, just move it into one of the real occasion folders
(`src/gallery-images/<occasion>/`) and commit.
